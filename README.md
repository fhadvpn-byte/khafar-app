# ميدان الخفر

تطبيق Streamlit ميداني لإعداد وثائق مرور العارضة (إحالات، محاضر، تقارير) مع توقيع حي بالمس، مرفقات صور/PDF، وأرشيف محلي.

## التشغيل المحلي

```bash
pip install -r requirements.txt
streamlit run app.py
```

## واجهة الجوال

- شريط تنقل أفقي: النماذج | الأرشيف | الإعدادات والبصمة
- تبويبات النماذج: الإقرارات (4) · المحاضر (4) · الطبية والجنائية (3)
- فتح النموذج بضغطة واحدة من بطاقة مدمجة

## المرفقات على الجوال

- الصيغ المدعومة: `png`, `jpg`, `jpeg`, `webp`, `pdf`
- تصحيح اتجاه كاميرا الجوال عبر Pillow (`ImageOps.exif_transpose`)
- تصغير تلقائي حتى 1200 بكسل وحفظ المرفقات في `session_state` حتى لا تختفي عند الاعتماد أو التوقيع
- معاينة فورية مع أزرار تحميل/حذف، وخيار إدراج المرفق في ورقة A4 المطبوعة
